# Online Assessment Live Monitor

A real-time coding assessment platform and proctoring dashboard connecting a candidate IDE with isolated script execution to a live proctor console for candidate monitoring, anomaly tracking, and assessment management.

---

## Features

### Secure Code Execution Engine
- **Sandboxed JavaScript Runs**: JavaScript solutions execute in Node.js `worker_threads` inside isolated `vm` contexts. Scripts exceeding a 3000ms timeout are terminated automatically.
- **Client-Side Python Execution**: Executes Python in the browser via Pyodide WebAssembly Web Workers, eliminating server evaluation overhead.
- **Casing Mapping Normalizer**: Automatically normalizes method casings (camelCase to snake_case) when matching outputs against target assertions.

### Real-Time Proctoring & Telemetry
- **Anomaly Detection**: Captures candidate events (tab switches, copy/paste infractions, code adjustments) and streams them in real time.
- **Fraud Score Indexing**: Computes weighted risk profiles for candidates based on flag telemetry.
- **Telemetry Batch Buffer**: Batches candidate tracking logs in memory and bulk-inserts them into MongoDB every 4 seconds.
- **Capacity Limits**: Caps telemetry storage at 150 records per session and limits active rooms to 100 concurrent users.

### Security & Authentication
- **Recruiter JWT Access Control**: Recruiter credentials hashed with `bcryptjs`. Endpoints and Socket.io handshakes verified via JWT.
- **Candidate Invite Codes**: Single-use invite codes generated by recruiters.
- **Session Isolation**: Separates recruiter and candidate token keys (`auth_recruiter` and `auth_candidate`) to allow side-by-side local testing.

---

## Tech Stack

- **Backend**: Node.js, Express, Socket.io, MongoDB, Mongoose, Worker Threads
- **Frontend**: React, Tailwind CSS, Monaco Editor, Pyodide (WASM)

## Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (Local instance or MongoDB Atlas)

### Installation

1. Install project dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in a `.env` file in the root directory:
   ```env
   PORT=3000
   MONGODB_URI=your_mongodb_connection_string
   JWT_SECRET=your_custom_jwt_signing_key
   ```

### Running Locally

Start backend server and frontend development environments:
```bash
npm run dev
```

Navigate to:
- **Login Portal**: `http://localhost:3000`
- **Recruiter Dashboard**: Sign up or log in as a recruiter to create assessments.
- **Candidate IDE Workspace**: Access using generated invite codes.
