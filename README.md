# Online Assessment Live Monitor

A secure, real-time coding assessment platform and proctoring dashboard. It connects a candidate-facing coding editor (featuring isolated script execution) with a live proctor console for monitoring candidates, tracking anomalies, and managing assessments.

---

## ✨ Features

### 💻 Secure Code Execution Engine
- **Sandboxed JavaScript Runs**: JavaScript solutions are offloaded to Node.js `worker_threads` and run inside isolated `vm` contexts. Infinite loops or resource-heavy scripts are terminated forcefully after `3000ms`, protecting server event loops from locking up.
- **Client-side Python Compiler**: Runs Python code inside the user's browser using WebAssembly via Pyodide Web Workers, eliminating server evaluation overhead.
- **Casing Mapping Normalizer**: Automatically normalizes method casings (camelCase ⇆ snake_case) when matching outputs against target assertions.

### 📊 Real-time Proctoring & Telemetry
- **Anomaly Detection**: Captures candidate events (such as tab blurs, copy/paste infractions, code adjustments) and streams them to the dashboard in real-time.
- **Fraud Score Indexing**: Computes weighted risk profiles for each candidate based on their flag telemetry.
- **Telemetry Batch Buffer**: Batches candidate tracking logs in-memory and bulk-inserts them into MongoDB every 4 seconds to optimize database connection performance.
- **Capacity Limits**: Limits telemetry storage records to 150 points per user session, and restricts active candidate room limits to 100 simultaneous users.

### 🔒 Enterprise-Grade Security & Authentication
- **Recruiter JWT Access Control**: Recruiters log in using password credentials hashed with `bcryptjs`. Endpoints and Socket.io handshakes are verified using signed JSON Web Tokens (JWT).
- **Candidate Invite Access Codes**: Candidates gain entry using single-use invite codes generated by recruiters. Once a code is used, it cannot be recycled.
- **LocalStorage Tab Isolation**: Separates recruiter and candidate token keys (`auth_recruiter` and `auth_candidate`) to enable side-by-side local testing in the same browser without account collisions.

## 🛠️ Tech Stack
- **Backend**: Node.js, Express, Socket.io, MongoDB, Mongoose, Worker Threads.
- **Frontend**: React, Tailwind CSS, Monaco Editor, Pyodide (WASM).

## 🚀 Getting Started

### 📋 Prerequisites
- **Node.js** (v18+)
- **MongoDB** (Local instance or Atlas Connection URI)

### 📦 Installation
1. Install project dependencies:
   ```bash
   npm install
   ```
2. Configure your environment variables. Create a `.env` file in the root directory:
   ```env
   PORT=3000
   MONGODB_URI=your_mongodb_connection_string
   JWT_SECRET=your_custom_jwt_signing_key
   ```

### 🏃 Running Locally
Start both the backend server and frontend development environments:
```bash
npm run dev
```
Navigate to:
- **Login Portal**: `http://localhost:3000`
- **Recruiter Dashboard**: Sign up or log in as a recruiter to start assessments.
- **Candidate IDE Workspace**: Access using generated invite codes.
